# PlanPlus

任务与状态规划应用。记录想法、管理日程、统计状态，让时间更有条理。

## 功能概览

### 日程
- 待办任务管理，支持时间轴与列表双视图
- 左滑切换至日程列表，右滑展开日期标签
- 支持截止日期、提醒时间、日程时段
- 筛选：全部 / 进行中 / 已完成

### 状态
- **多维状态记录**：活动性质（精力/体力使用、动机、产出）、状态指标（情绪、精力、生理、注意力）、活动标签（通勤、会议、就餐、运动、学习、休息、睡眠等）
- **预设管理**：保存常用配置为预设，支持图标/颜色、置顶、按拼音分组、搜索、导入导出
- **活动标签**：内置标签可隐藏，自定义标签可增删，支持恢复默认
- **定时提醒**：底部弹窗问卷，推荐预设 + 概率，选择更多进入完整预设列表
- **预定免打扰**：提前设定时段（如睡眠 22:00–07:00），到点自动填充不提醒
- **历史推荐**：同一时段的历史记录统计推荐预设，无数据时默认规则（如 2:00–10:00 默认睡眠）
- **批量设置**：事后修改选定时间范围的记录
- **统计页**：维度统计图（时间范围、维度、条形/折线/饼图）
- **状态页**：过去 24 小时记录倒序列表，单条编辑、长按多选批量修改

### 想法
- 多会话想法笔记，聊天气泡式界面
- 右侧抽屉管理会话历史
- 多选消息导出：复制或分享
- 导出格式：每条「时间 + 内容」或多条拼接

### 智能
- 中间入口占位，后续接入智能体 / 语音

### 统计
- 维度统计图：按时间范围、维度（活动标签、精力使用等）、图表类型（条形/折线/饼图）可视化状态分布

### 设置
- 主题：浅色 / 深色 / 跟随系统
- 主题色：7 种可选
- 统计单位：15 / 20 / 30 / 60 分钟
- 提醒间隔：30 / 60 分钟
- 静默时段：开始 / 结束时间，未记录时默认预设
